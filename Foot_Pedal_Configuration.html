Infinity Foot Pedal Setup

Configure and test the VEC Infinity 3-pedal foot control in this browser.

1. Connect the pedal

Not connected. Use Chrome or Edge on an HTTPS page, then choose the VEC Infinity device.
Device: —VID/PID: —

The Infinity sends pedal signals to the computer; it does not expose writable configuration reports. This page remaps those signals in the browser instead of trying to rewrite the pedal's firmware or memory.

2. Assign each pedal

Choose a key and how it should behave. Settings are saved in this browser on this device.

Defaults: Left = Left Arrow, Center = Space, Right = Enter. Mode: Hold while pressed.

4. How to use these assignments in an activity

When a pedal is pressed, this page dispatches an in-page keyboard event and a custom infinitypedal event. Your scanning activity can listen for these events while this page is open. It cannot send system-wide keystrokes to unrelated tabs or programs.

Use this listener in an activity page to receive pedal events.
document.addEventListener('infinitypedal', function(event) {
  const pedal = event.detail.pedal; // 1 = left, 2 = center, 3 = right
  const action = event.detail.action; // key name, e.g. "Space"
  const phase = event.detail.phase; // "press", "longpress", or "up"
  // Connect these values to the activity's switch action.
});
