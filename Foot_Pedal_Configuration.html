Infinity Foot Pedal Setup

Remap the three VEC Infinity pedals for supported browser activities — no Pedable installation needed.

1. Connect the pedal

Not connected. Use Chrome or Edge on an HTTPS page, then choose the VEC Infinity device.
Device: —VID/PID: —

The Infinity does not have writable assignment memory. This page translates its three signals into the keys you choose. The page will not claim the device automatically. This preserves the pedal's normal keyboard behavior on other webpages.

2. Assign each pedal

Choose the key each pedal should send to a supported activity. Single press or long press can be set separately for each pedal. Settings are saved in this browser.

Defaults: Left = Left Arrow, Center = Space, Right = Enter. Each uses single press.

4. How to use these assignments in an activity

When a pedal activates, this page sends an in-page keyboard event and a custom infinitypedal event. The assignments work in this page and activities that include the integration code; they do not change system-wide keys in unrelated programs.

Use this listener in an activity page to receive pedal events.
const pedalChannel = new BroadcastChannel("vecInfinityPedalEvents");
pedalChannel.addEventListener("message", function(event) {
  const pedal = event.data.pedal; // 1 = left, 2 = center, 3 = right
  const action = event.data.action; // assigned key name, e.g. "Space"
  const phase = event.data.phase; // "press", "longpress", or "up"
  // Connect these values to the activity's switch action.
});
